简介:
一款为《Degrees of Lewdity》打造的AI扩展Mod，在原版世界观与数值体系基础上，生成动态剧情、场景配图、专属道具与记忆系统，全程对游戏变化做校验，不破坏原版存档与核心玩法。
> 适配环境：游戏 v0.5.11.9 Lyra 1.0.0a 0815 + ModLoader 2.x
> 当前版本：v0.1.685
> 项目地址：https://github.com/Kanna-destiny/WovenRealm
> 下载地址：https://github.com/Kanna-destiny/WovenRealm/releases/latest

✨ 核心功能
1. **动态剧情**
   原版场景可自动/手动生成剧情分支，地点跳转时能补全过渡剧情；支持自由输入想做的行动，让AI续写发展，剧情结束后自动生成后续选项。
2. **选项自由修改**
   每条AI选项都支持编辑：可改写文字、调整行动耗时，也能一键重置，完全按你的想法推进剧情。
3. **安全数值校验**
   AI提出的时间、属性、金钱、NPC关系、道具等变化，都会经过系统范围校验，通过后才写入游戏，避免乱改数值、破坏平衡。
4. **剧情记忆系统**
   分为短期记忆（保持当前剧情连贯）和长期记忆（保存重要事件、关系、线索），记忆随单份存档独立保存，不会跨档串档。
5. **织境道具与补位装备**
   AI剧情中出现的物品可收入专属库存；支持将道具配置为补位装备，和原版穿戴叠加生效，支持叠戴、装备方案与多种生命周期。
6. **AI场景配图**
   可根据当前剧情自动生成生图提示词，支持中英双语调整、一键出图；可保存玩家与NPC外观，让画面更贴合你的设定。


## 🚀 第一次使用
1. 进入「设置 → 织境空间 → 剧情AI设置」。
2. 选择接口服务商，填写API密钥、接口地址与模型，点击保存。
3. 使用页面内的「连接体检」测试接口连通性。
4. 推荐新手开启「手动」剧情生成模式，确认稳定后再切换自动。
5. 因Mod较复杂设置里菜单较多,如果不清楚设置里的作用可阅读(?),如果实在搞不懂建议使用默认设置。

## 🚀 Mod操作
- Mod正常启动后,可以在游戏选项中出现[剧情生成]按钮,点击后可以进入剧情延伸模式。
- 窗口下方会出现Ai剧情延伸窗口和自定义剧情输入窗口,可以自行决定剧情走向。
- 如果设置里勾选了生图并正确设置后,剧情窗口下会出现剧情生图窗口,可以根据当前情景生成贴合当前剧情的图像。
- 如果剧情中出现了(可拿取的物品) 剧情下会出现提示,可以点击按钮得到道具。剧情中可以点击(使用道具)按钮,下一段剧情将根据使用剧情和物品效果进行剧情延伸.
- 可以在日志窗口中看到物品菜单和记忆菜单用于个性化调整,物品菜单可以将物品设置为(装备)。
- 人物属性中装备页可以调整附加装备并设置装备附加属性.(附加装备可叠加在官方装备上)。

## ⚠️ 注意事项
- Mod仅负责整理游戏上下文与调用你配置的AI服务，剧情质量、生成速度取决于你使用的模型与接口。
- 重要剧情前建议手动存档，AI剧情回退不能替代完整存档
- 配置文件包含API密钥，请勿公开分享；反馈问题请导出诊断报告，而非配置文件
- 若遇报错、显示异常，先保留现场，在「诊断」页导出错误报告再反馈(点击设置-织境空间-诊断-导出错误报告发给咱即可)
- 如游玩过程中出现剧情离散、丢失内容、tekno消耗急剧增加。请先去日志菜单检查Ai记忆是否过长,可以进行记忆压缩或精炼剧情。
